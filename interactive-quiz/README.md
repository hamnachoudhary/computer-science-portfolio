# Interactive Quiz App

## Overview
A beginner Python quiz that tests basic Computer Science knowledge.

## Features
- Asks the player for their name
- Presents two multiple-choice questions
- Checks answers and updates the score
- Calculates the final score and percentage

## Python Concepts Used
- `input()` and `print()`
- Variables and user input
- `if` and `else` statements
- String methods such as `.lower()`
- Arithmetic operations
- Score tracking
